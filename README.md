# Eco Car Cup Pacer

富士スピードウェイで開催される **Eco Car Cup 2026 Challenge 180** 用の、GPSラップペースアプリです。
目標ラップタイム（デフォルト 3'15"00）ちょうどでコントロールラインを通過できるよう、走行中にリアルタイムで
「加速すべきか / 減速すべきか」を表示します。

## 表示内容

- 目標タイムまでの残り時間（超過した場合は赤字で `+` 表示）
- コントロールラインまでの直線距離（m）
- 現在のペースに対して、加速（上矢印・青）／このままでOK（チェック・緑）／減速（下矢印・赤）を大きなアイコンで表示
- 現在の速度、GPS精度、直近のラップ履歴（目標タイムとの差）

## 使い方

1. アプリを起動し、位置情報の利用を許可する。
2. 右上の旗アイコンから設定画面を開き、コースのコントロールラインを通過する瞬間に
   「今コントロールラインを通過」をタップしてキャリブレーションする（現在地と進行方向を記録）。
3. 1周走ると、その周の軌跡を目標タイムに換算した「基準ペース」として自動的に記録し、
   2周目以降はリアルタイムで加速・減速の判定が表示される。
4. コントロールラインを通過するたびに自動でラップが区切られ、タイマーがリセットされる。

目標タイムは設定画面で変更可能（Challenge 180 のデフォルトは 3'15"00）。

## 仕組み（概要）

- コントロールラインは「通過した瞬間の緯度経度＋進行方向」として保存し、以後はその直線を横切ったかどうかで
  周回検出を行う（誤検出防止のため、ライン付近・進行方向が近い場合のみ・前回通過から一定時間経過後のみ判定）。
- 通過検出のたびに、その周の「走行距離 → 経過時間」の軌跡を目標タイムにスケール変換し、次周の基準ペースとして使う。
- 走行中は、現在の走行距離に対して基準ペースでは何秒経過しているはずかを常に計算し、実際の経過時間との差から
  加速・減速を判定する。

## 注意事項

- スマートフォンのGPSは更新頻度・精度に限界があり（数m〜十数mの誤差、通常1Hz程度の更新）、本アプリの表示は
  あくまで目安です。コンマ秒単位の完全な精度は保証されません。
- **運転中の操作は絶対に行わないでください。** 設定・キャリブレーションは必ず停車中またはピット内で行うか、
  同乗者が操作してください。
- 本アプリは大会公式のものではなく、非公式の個人用ツールです。実際のペース判断・走行はドライバー自身の
  判断と責任で行ってください。
