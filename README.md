# Eco Car Cup Pacer

富士スピードウェイで開催される **Eco Car Cup 2026 Challenge 180** 用の、GPSラップペースアプリです。
目標ラップタイム（デフォルト 3'15"00）ちょうどでコントロールラインを通過できるよう、走行中にリアルタイムで
「加速すべきか / 減速すべきか」を表示します。

## 表示内容

- 目標タイムまでの残り時間（超過した場合は赤字で `+` 表示）
- コントロールラインまでの残り距離（m）
- 現在のペースに対して、加速（上矢印・青）／このままでOK（チェック・緑）／減速（下矢印・赤）を大きなアイコンで表示
- 現在の速度、GPS精度、直近のラップ履歴（目標タイムとの差）

## ペースの判定方法

「今の速度を維持したまま残りの距離を走ると、目標タイムより早くコントロールラインに着くか・遅く着くか」を
常に計算して判定する。

- 早く着く見込み（速すぎる） → 減速（下矢印・赤）
- 遅く着く見込み（遅すぎる） → 加速（上矢印・青）

過去の周回データに依存しないため、**キャリブレーション後の1周目からペース判定が有効**になる。
コントロールラインを通過するたびに、経過時間・残り距離のカウントは自動的にリセットされ、次の周の判定が始まる。

## 使い方

1. アプリを起動し、位置情報の利用を許可する。
2. 右上の旗アイコンから設定画面を開き、コースのコントロールラインを通過する瞬間に
   「今コントロールラインを通過」をタップしてキャリブレーションする（現在地と進行方向を記録）。
3. 走行中はリアルタイムで加速・減速の判定が表示される。コントロールラインを通過するたびに自動でラップが
   区切られ、タイマーがリセットされる。

目標タイムは設定画面のホイールピッカー（分・秒）で変更可能（Challenge 180 のデフォルトは 3'15"00）。

設定画面からは、コントロールラインを緯度経度の手入力で設定することもできる（Google Mapなどで座標を調べて貼り付ける）。

### 走行ライン（コースパス）※任意

設定画面の「走行ラインを編集」「走行ラインを走って記録」から、コントロールラインを起点とした1周分の走行ラインを
あらかじめ定義できる。設定すると、コントロールラインまでの残り距離が直線距離ではなくこの経路に沿った距離になり、
より現実の周回に近い値・より正確なペース判定になる。入力方法は3通り。

- **走って記録する**: 「走行ラインを走って記録」から、コントロールライン通過の瞬間に「記録開始」、1周してライン
  に戻ってきたら「記録終了」。コントロールラインが未設定の場合は、記録の開始点をそのままラインとして設定するか
  どうか選べる（あとから「今コントロールラインを通過」でいつでも上書き・修正できる）。
- **地図をタップして点を置く**: コーナーの頂点や道なりの変化点を中心に、コントロールラインから走行順に1周分
  タップする。地図上には現在設定されているコントロールラインがオレンジの旗で表示される。
- **GPX/CSVを読み込む**: データロガー等の出力をファイルまたはテキスト貼り付けで読み込む。CSVは1行ごとに
  「緯度,経度」または「緯度,経度,経過秒」。

この設定は任意で、行わなくてもコントロールラインまでの直線距離をもとに動作する。

## 仕組み（概要）

- コントロールラインは「通過した瞬間の緯度経度＋進行方向」として保存し、以後はその直線を横切ったかどうかで
  周回検出を行う（誤検出防止のため、ライン付近・進行方向が近い場合のみ・前回通過から一定時間経過後のみ判定）。
- 走行ラインが設定されている場合、現在地をその経路上に投影して「経路に沿ったコントロールラインまでの残り距離」
  を計算する。未設定の場合はコントロールラインまでの直線距離を使う。
- 上記の残り距離と現在の速度から「今の速度のまま走ると何秒後にラインへ着くか」を予測し、目標タイムとの差から
  加速・減速を判定する。

## 注意事項

- スマートフォンのGPSは更新頻度・精度に限界があり（数m〜十数mの誤差、通常1Hz程度の更新）、本アプリの表示は
  あくまで目安です。コンマ秒単位の完全な精度は保証されません。
- **運転中の操作は絶対に行わないでください。** 設定・キャリブレーションは必ず停車中またはピット内で行うか、
  同乗者が操作してください。
- 本アプリは大会公式のものではなく、非公式の個人用ツールです。実際のペース判断・走行はドライバー自身の
  判断と責任で行ってください。
